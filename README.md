# 禁煙外来 動機づけ面接シミュレーター（シナリオ完結版）

禁煙外来の初診場面で、医療者として返答を選びながら動機づけ面接（Motivational Interviewing; MI）を練習する、ブラウザで動く教育用デモです。

- 返答は3択×5回。選んだ返答に応じて、架空の患者「ネコタ・タマさん」が音声で答えます。
- 返答ごとに MI の行動分類（開かれた質問、複雑な聞き返し、是認、説得・警告など）と短い解説が表示されます。
- 最後に、MITI 4.2.1 の考え方を簡略化した指標（聞き返し÷質問、複雑な聞き返しの割合、MI一致・不一致の行動数）を表示します。

## 使い方
公開ページを開き、「面接をはじめる」を押してください。音声が流れます。

## 注意
- 登場人物・会話はすべて架空です。医療上の助言を目的としたものではありません。
- 指標は教育用の簡略版で、MITI の正式なコーディングや評価基準の代わりにはなりません。
- 音声は Google Gemini TTS（gemini-2.5-flash-preview-tts）で生成しました。

## 作成
香田将英（東北大学大学院医学系研究科 公衆衛生学分野）。第94回医学教育セミナーとワークショップ WS-4（2026年10月10日）のデモとして作成。
